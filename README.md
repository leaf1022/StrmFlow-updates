# StrmFlow 更新公告

本仓库仅提供 StrmFlow 的正式版本公告、更新说明和公开 Docker 镜像信息，不包含私有业务源码。
源码仓库继续保持私有；不需要维护第二套业务代码或第二套版本号。

## 已发布版本

- 正式版本：`v0.1.39`
- 固定镜像：`leaf1022/strmflow:0.1.39`
- 滚动镜像：`leaf1022/strmflow:latest`
- 当前两者指向相同镜像内容；目前仅支持 `linux/amd64`。
- 镜像 digest：`sha256:50a24f3b8d6892caa2fbd67041ff318b35ee465f1815dd7f23bcf80fba736e98`

`latest` 只是最新正式镜像的滚动标签，不会使运行中的容器自动更新。
固定 tag 用户需先调整 Compose 镜像版本；latest 用户可以手动执行：

```bash
docker compose pull && docker compose up -d
```

更新前请备份自己的配置和数据库。本项目不要求挂载 Docker socket，也不会自动拉镜像、重启或部署。

## 0.1.39 更新内容

- 限制 115 目录映射缓存最多 4096 条，并增加 10 分钟过期时间。
- 扫码授权会话增加 10 分钟过期，避免授权信息长期驻留。
- 海报缩略图缓存改为受 600 条和 32 MiB 双重限制的 LRU。
- 302 播放中转缓冲改为池化复用，降低并发播放时的临时内存分配。

本版本不改变业务行为，不需要迁移数据库。

## 更新检测

接入本仓库的后续构建匿名请求本仓库的最新正式 Release，无需私有源码仓库 Token。
启动一分钟后检查，之后每 12 小时检查；可在系统配置里关闭或手动检查。
当前 `v0.1.39` 与 `latest` 均包含公告源接入代码；检测只读取本仓库的公开 Release，不访问私有源码仓库。

## 发布规则

私有源码、镜像和本仓库公告使用同一个版本号。先完成对应源码与镜像发布及验证，再发布相同版本的公告。
这里只发布可公开的说明，不上传私有业务源码、配置、日志、用户数据或凭据。GitHub 自动提供的源码归档只包含本公告仓库内容。
